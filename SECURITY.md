# Security policy

Chistara (hoghogh.ai) takes the security of its users' accounts and data seriously, and welcomes reports from researchers.

## Reporting a vulnerability

- **Private report on GitHub:** use *Report a vulnerability* on the affected repository's **Security** tab, or
- **Email:** info@hoghogh.ai with the subject `Security: <short title>`.

Please include what you found, the steps or a request that reproduces it, and the impact you expect. Do not include other
people's data in the report, do not access accounts that are not yours, and do not run tests that could degrade the service
(load tests, automated scanning at volume).

We acknowledge a report within 3 working days, keep you informed while we fix it, and credit you when it is resolved if you
wish. Please give us reasonable time to fix an issue before you disclose it publicly.

## Scope

- https://hoghogh.ai, https://ir.hoghogh.ai and the Chistara apps for Android and iOS
- The MCP server at https://hoghogh.ai/mcp (`ai.hoghogh/chistara`)

A personal MCP connection link is a credential: if you find one exposed anywhere, report it and do not use it.
